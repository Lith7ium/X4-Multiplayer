Production review and executable checks
---------------------------------------

The outer replay retains RAX through the continuation jump. The sampler takes
its actual incoming return slot before forwarding; the fixed parent-frame
reads retain exact caller, descriptor/frame and selected Action identity.
The new finally paths drain only private observer scopes on abnormal return.
No repeat getter, native reference acquisition, RNG write or correction appears
in these wrappers. Configuration is default-off; healthy reattachment is an
acknowledgement retaining counters, records and export cursor.

Installation/restoration holds its own lock, retains byte ownership independently
from protection/cache debt and preserves foreign words. Event publication is
complete-only. Partial guard failures, excess calls, unsupported data, STOP
overlap and abnormal completion remain failed evidence. The parser joins each
receipt to a completed selected Action and its validated downstream Value;
global unknown-owner failures remain separate and strict.

Findings and corrections
------------------------
Four additional witnesses were reproduced against the original actual C export:
changing a space vtable in both copies, changing a valid RTTI name in both copies,
misaligning the sampler return slot by one byte, and appending 2100 spaces to an
event row. The original parser accepted all four and allowed a claimed paired
pass. These were evidence-validation defects, not observed native divergences.

The corrected parser retains validated space/reference class information in
paired semantics: image-relative class addresses, RTTI name, bitmap and COL.
These fields are explicitly Windows-image diagnostics. Coherent class changes
remain individually supported captures but are now visible differences, so a
claimed equality is rejected. Raw local object pointers are not canonical IDs.

Both native and parser guards now require incoming T modulo 16 to equal 8.
The corrected positive fixtures reflect the actual ABI; a wrong aligned-frame
claim is refused while the native original still runs once. Raw record length
is checked before newline removal, closing the trailing-whitespace bypass.
The exact original witnesses were rerun on the final archive and all four now
reject claimed equality. No old failure was waived.
