Explicit third import-Wait / Find composition - 28 October 2026

Scope and reason
This source-only change adds one opt-in composition for the previously observed
6d945/move.idle saved Wait, alongside the two existing Wait interventions and the
unchanged selected FindComponent intervention. It adds no hook, RNG algorithm,
native getter, callback ownership, or broad Wait selector. No game, installation,
World015 package or old evidence changed. Test outputs are private offline builds.

The arithmetic report eb3360e correctly reconstructed the unequal World014
deadlines and proposed a third-entry policy change. Independent review found
that the policy alone cannot run with Find: the old builder pins policy file
66dc5770..., and the native Find dependency explicitly requires entry3 to observe.
This is experiment composition pinning. Find's 179-byte semantic seed and actual
anchor depend on pilot9d3a4/order3cdb, not on pilot6d945's incoming stream.
The new composition is explicit; those old guards are not broadened in place.

Native guards and retained configuration
First configuration parses the exact wire and latches composition1 or2 together
with the existing manifest/shape/seed/digest. The old predicate is unchanged.
Composition2 requires the complete exact three-entry policy wire, schema2 and
snapshot words. It also checks every parsed entry in order: saved ID, bounded
name/text, version, index, native time/minimum/maximum bits, intervention policy,
slot, PC, since, seed and script/time hashes. Foreign reordering, policy changes,
extra/missing entries and changed scalar guards refuse. No observe-or-intervene
fallback exists. The new string comparisons read only known bounded fields.

The same retained composition and dependencies are checked for read-only healthy
UI reload acknowledgment. No counters, buffers, cursor, seed or callback is reset.
Cross-mode reattachment, late first install, STOP, existing failure/open/restore
debt and foreign callback/closing dependency guards retain their refusals.
Original-call, borrowed-input, finally, same-TLS restoration and locking code is
unchanged. The separate Wait wrapper still supports normal-return cleanup only;
this change does not add native Wait exception safety or general ambient RNG
synchronization. Unrelated global unknown coverage remains an error in the full
session validator.

Evidence and builder composition
The builder checks the exact snapshot, observation, policy and Action file
digests for the selected descriptor. Both reviewed combinations are supported:
old Find plus old policy, and new Find plus new policy. Both crossed pairs refuse
before output creation. Existing action/observation byte pins remain unchanged.

Only the new native STOP uses schema2 and appends composition=<descriptor SHA>.
Event and identity rows retain the old layouts and Find seed. The independent
parser requires exact new configuration, snapshot and observation/policy wires;
it joins all three validated raw Wait records with the actual scoped-RNG receipts,
requiring applied/restored proof, original policy/count/phase guards and retained
failure semantics. A manifest alone is insufficient. A natural third receipt,
missing rows, failed raw validation, changed selector or wrong STOP composition
cannot report the selected scope valid. Paired comparison requires the same
composition; matching Find output under different compositions is insufficient.
