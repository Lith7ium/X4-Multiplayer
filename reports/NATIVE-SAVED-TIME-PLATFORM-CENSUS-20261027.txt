SAVED AI TIME: WINDOWS/LINUX PARSER DIFFERENCES
27 October 2026

The two audited decimal parsers predict different imported time bits for 2,262
of the 38,448 saved AI script records in the current test snapshot. All 38,448
time strings fit the bounded plain-decimal grammar; there are 399 distinct
strings, of which 13 produce different results. This is static arithmetic
evidence on actual saved inputs, not a live cross-platform state comparison.

Windows 14c3090 uses separate binary64 fractional operations with scale *= 0.1.
Linux 1a3b1a0 uses scale /= 10.0. Both then multiply the digit by the scale and
add it to the accumulated value. The XML readers are Windows 12fd30 and Linux
1df4a70. The saved ExecState time stores are Windows b5a734 and Linux 10df2d9.
Full paths and exact-image pins are retained in the saved-decimal conversion
and Linux/Windows Wait-import reports. No engine function is executed by this
audit, and no native value is rounded, replaced or excluded.
