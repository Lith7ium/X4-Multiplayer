Observer and integration

New default-off world_wait_trace_config accepts at most8 explicit saved pilot/
script/version/XML-index/start-time/constant-range records. The overlay builder
checks the manifest against the exact snapshot SHA, saved AI stack and declared
script versions. It never enables the observer implicitly. A changed manifest
retry is refused; an exact retry does not reset storage or reinstall hooks.

Only10a50d0 is patched, using an aligned8-byte CAS with a5-byte jump and the upper
3 bytes preserved. Reserved resident thunks2752..2815 replay the exact original
5-byte instruction and dispatch the unchanged three arguments. No return
override, RNG seed, time correction, queue write or second hook is present.

Bootstrap review found that start_gate publishes the main FrameTick hook before
lua_boot finishes installing optional hooks; Wait configuration is later still.
Boot phase0 bypasses barriers but does not stop the main thread from entering the
shared trampoline page. Removing execute permission from that page at configure
time was therefore unsafe, even though earlier emitters used the same pattern.

The Wait emitter now runs in make_thunk on the private RW allocation before its
first RX transition, cache flush and main-hook publication. It writes only the
reserved64 bytes. Disabled observation does not require Wait-specific pins.
Configuration checks the complete frozen64 bytes, RX protection and full pins,
then publishes only the engine entry patch. Exact retries also verify entry
ownership. Wait configuration performs no shared-page protection change or code
write. Conversion of older shared-page writers is separate integration work;
this child has not claimed that those older paths are safe or launched native007.

The all-call admission lock closes at restoration and records open/peak/restore
overlap. It also protects hook publication from a concurrent STOP. Refused late
entrants still invoke the resident original once. Complete events publish only
after exit validation; overflow, missing mapping, changed lifetime/input,
unsupported expression/version/phase and STOP overlap remain failures.

Selected calls require exact importer return1069bfc, a stable tagged AI context
of the pinned native class, nonzero native lifetime, owner runtime ID mapped to
the manifest's saved pilot, script identity/name/version, bounded program vector
and exact node at the blocked native slot. Inputs are read again before and
after original execution. Timer/reason/flags/RNG and native clock/load-indicator
samples are guarded against changing copies. No engine getter is used.

The expression observation preserves all104 raw range bytes, auxiliary timeout
Value and listener pointer. Supported interpretation requires constant numeric
bounds, min/max mode2, uniform distribution1/sample count1, absent explicit seed/
basis and absent auxiliary timeout/listeners. Unsupported cases still execute
the original once and export the available raw evidence with failure bits.

The bounded phase is boot2/tick0 within120s of boot start. It records actual UI/
main thread matches, TLS view, app load bit, VBI loading flag and native clocks.
It does not assume import runs on the UI thread and does not equate boot2 with
being inside the native GameClass::Load function.

Each of at most128 events exports four bounded lines. Local addresses, lifetime
IDs, raw expression bytes and real elapsed time remain diagnostics. Comparison
uses canonical saved owner/script and semantic inputs/outputs, not global
cross-thread order or process-local pointers. Existing whole-world raw roots,
queue traces and all unknown-domain coverage are unchanged. The strict validator
requires the configured Wait trace; missing or unexercised selection is failure.
Main validation also retains per-client coverage/samples, semantic equality and
individual differences. A claimed barrier pass with unequal Wait semantics is
rejected. A failed barrier may still provide valid negative observations; its
existing errors, first mismatch and session failure are never replaced.

The saved XML blocking ordinal and native program slot are separate fields.
Direct runtime ordinal corroboration is explicitly unsupported: no native

the resulting deadline/RNG still need a fresh reviewed two-game observation.
