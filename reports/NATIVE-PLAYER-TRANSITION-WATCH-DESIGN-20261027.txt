SEPARATE SAVED TRANSITION WATCH AND LEGITIMATE ACTION PROPOSAL
27 October 2026 | Read-only source design; no live/control authorization

Purpose

Permit read-only observation of saved controlled ship ae79c, initially a
PlayerController, without rebinding a raw world watch or calling a lazy native
getter. The original world-watch/queue/parser path and its strict failures remain
unchanged. This proposal does not provide a second native player context.

   Duplicate, conflicting, late or unobserved imports refuse. Full reads begin

Fresh identity guard, audited against ced70/184

Native ComponentRegistry::Find uses index=(runtime & 0x1ffffff)-1, one of32 page
slots at registry+58+8*(index>>20), and page index index&fffff. Each32-byte block
holds three pointers; block=(page_index/3)*32, lane=page_index%3. Its status nibble
is extracted from block+1c at bit16+4*lane. Occupancy bit1 and the caller's mask4
must be present. Its16-bit generation comes from block+18+4*(lane/2), shifted
16*(lane%2), and must equal (runtime>>25)&ffff. The selected slot pointer must
equal the imported object and component+8 must equal the entire runtime value.

Implement a bounded ReadProcessMemory-backed version, not a native helper call:
checked address arithmetic, nonnull root/page/slot, two matching reads of selected
pointer/status/generation, fresh full object ID, exact Small vtable, macro and
true owner from+348. Validate controller type Nav2c51158 or Player2c39488,
controller+28 owner, +30==Agent+ad0, +40 Agent, Agent+ef0 owner, owns+58 and f79.
The imported object/full runtime/Agent remain fixed through transfer. Initial
controller type must match the manifest. Never read the destroyed old controller
after publication; read the object's actual published pointer first.

These are sequential read guards. They neither retain a native component nor
exclude concurrent owner changes, destruction, child allocation reuse, or eventual
generation wrap. atomic_lease/generation_exclusion/faction_exclusion remain zero.
Prebind callbacks are counted as excluded coverage, not read as complete objects.

Receipt lifetime and stop contract

Enqueue: independently admit/count the callback, select the imported recipient,
check current registry/object/owner/Agent continuity and exact manager pointer,
copy the16-byte SetFlightControlModelOrder (vtable2c51c38, uint32 mode+8 in0..6),
and allocate a unique ticket before the native enqueue transfers ownership.
No command access after enqueue original. An outstanding address cannot be reused
as another ticket. Retired address reuse receives a new monotonic ticket.

Dispatch: at existing eacf60, require caller eacf66 and one live exact
(ticket,recipient full runtime,command address,Agent) tuple. Copy/compare input
before original, claim ticket once, then capture result and unchanged command
before the native destructor at eacf77. Retire the exact tuple after return.
Missing, duplicate, changed, unreadable, stale generation and wrong-Agent receipts
fail. A consumer skipping the recipient leaves an outstanding ticket and cannot
prove completion. Unsupported selected command types have explicit coverage;
model receipt completion does not prove the manager or other producers drained.

Admission/STOP use consistent own locking, count all admitted calls before
selection, retain peak/restore_open, and never hold a lock over a native original.
An open callback may finish into resident storage after STOP; restore_open remains
failure. Closing forbids config/import/admission reopening. Existing world queue
restoration still owns its sites; transition closes before that restoration.
Own window may extend to120 ticks while raw world tracing remains bounded at12;
this changes observation coverage only, never gate continuation or clock policy.

Configuration and tests before live review

Order: exact build/pins -> gate boot -> raw world/queue configuration -> separate
transition manifest -> existing three transition hooks -> load -> successful
imports -> joined binding -> observe. Same manifest may be retried by UI reload;
changed manifest or late first configuration refuses. No new numeric option bit.

Tests use owned synthetic registry pages and actual production wrapper calls:
all three slot lanes/page boundaries, generation/type/occupancy mismatch, replaced
object, replaced Agent, changed owner, duplicate/late import, incomplete load,
actual-image pins; Nav->PC and PC->Nav transfer with delayed model dispatch;
missing/changed/duplicate ticket, immediate address reuse after retirement,
consumer completing before enqueue returns, poisoned post-enqueue storage;
unselected nested calls, overlapping raw and transition watches, original once,
STOP during config/import/dispatch and every restore failure. Existing raw queue
fixtures must retain byte-identical rows/errors. Independent parser tampering must
not turn a partial or invalid receipt into completion or authority.

The stock docked-menu button calls bool GetUp(void), export1aba30. It checks native

simulation time+0.01. A true return means queued request only. GetUpEvent dispatch

The8 newly checked complete static ranges/three slots are recorded separately in
NATIVE-PLAYER-TRANSITION-ACTION-PINS-20261027.json; the prior97-pin audit remains.

Re-entry uses the stock interaction menu's PerformCompSlotPlayerAction(compslot,
actionid) export1b5450, not direct716670. ABI: UIComponentSlot is16 bytes (full
component ID,const char* connection), passed by reference in RCX under Windows;

container from virtual+1338, bounds the index and invokes container+90.
MainTypeInstantActionContainer+90 ->3508e0 resolves its native target then invokes
the action's+10; ControlPositionAction+10 ->35b8a0 reaches audited entry716670 or
requests an occupying NPC leave first. Its bool is not model-completion ACK.
