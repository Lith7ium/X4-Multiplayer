Scope
-----

Failure independently reproduced
-------------------------------
The frozen World011 probe sent each C world page directly to DebugError.
WORLD_HASH_PAGE is 12; the C output buffer is 12288 bytes. Dense Nav V2 rows fit
that buffer but exceed the observed logging bound.

Each client's tick 2 contains 834 truncated page blocks. Each block has ten
774-byte rows, followed by 440 bytes of its eleventh row; the twelfth is absent.
Including LF terminators this is 10*775 + 440 + 1 = 8191 bytes. The stored CRLF
form is 8202 bytes. The summary declares 10008 changed objects, but only 9174
object lines survive: 8340 full rows plus 834 partial rows. This is a logging
failure, not evidence that the C buffer or Nav canonicalizer omitted rows.

Replaying the unchanged frozen world parser produces 3342 errors per client:
834 malformed timing fields, 834 missing Nav raw fields, 834 incomplete enriched
timing receipts, 834 selector/capture mismatches, one incomplete delta, one
independent root mismatch and four detail/hash mismatches. Sparse reconstruction
retains the previous phase for missing rows, explaining the selector failures.
The complete run validator also reports other errors; none are waived here.

Two watched motion records retain complete tick-2 object rows and one complete
206-byte detail each. Each detail's SHA256 matches its same-frame object hash,
and the peer details differ. Those localized differences are real observations;
the incomplete census cannot establish that they are the only differences or
that any whole-world domain is equal. Causal analysis remains separate.

Implementation
--------------
Only tools/dev/native_gate_probe.lua changes production behavior. Each native
page is validated as a nonempty string below 12288 bytes and divided at its
existing LF boundaries. Each DebugError call is at most 6000 bytes. Every byte,
row and order from the page is preserved; no values are normalized or filtered.
Empty rows, unterminated rows, and a single row exceeding 6000 bytes fail through
the existing probe error path. The entire page is checked before its first
chunk is emitted. A rejected page therefore cannot produce a frame hash/report.
Native capture, page size, hashing, exports, schemas, selectors, parsers and
default V1 configuration are unchanged.
