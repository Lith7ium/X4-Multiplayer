Purpose and scope
-----------------
Make the earlier relay, game adapters and distribution tools understandable to
human reviewers while preserving their behavior. The newer Rust/dedicated
implementation and engine hooks remain outside this cleanup.

Changes:
- Four-space indentation, expanded control flow, one statement per line and
  predictable formatting across the adopted Python/Lua/MD XML files.
- Domain names for local packet fields, poses, claims, generations, engine
  adapters, state tables and file operations. Public compatibility names remain.
- Comments/docstrings explain responsibility, units, authority and engine
  constraints. No new protocol or state model is introduced.
- Expanded C and PowerShell control flow and descriptive local variables.
- Optional formatter configuration, an explicit file manifest, a check/fix
  command and docs/CODE-STYLE.md with a module map and primary references.

Review the pure-format commits separately from the subsequent name changes.
The formatter manifest intentionally excludes experiments, generated packages,
test fixtures and newer implementation areas. Existing tests are not broadly
reformatted. Four test files changed only where five assertions assumed compact
source layout; they now inspect Python AST or XML structure and action order.

Limits and integration
----------------------
No native X4 launch, live Windows test or joint gameplay test was performed.
Automated equivalence checks and passing tests reduce regression risk; they do
not prove absolute error freedom or fix pre-existing gameplay defects.

The pre-existing standalone prepare.py import-path issue is outside this cleanup;
the existing test runner supplies src/ on sys.path. This report does not claim
that every historical command works from every environment.

No normal profiles, saves, Workshop state, sealed packages or tracked compiled
artifacts were changed. Onboarding instructions and monitor schedules remain
unchanged. Integration belongs to Ferrite; this branch is offered for review,
not as a new release or native gameplay acceptance.
