PUBLICATION, STOP, EXCEPTIONS AND UNSUPPORTED CASES

An observer-owned bounded ring holds selected attempts and immutable copied
identity/input/RNG fields. All calls have explicit admission; selected attempts
have a single-use owner occurrence. Seed publication and STOP admission closure
are serialized by the new scope lock; no lock spans original engine execution.
Do not nest the new lock with Position/Find/Wait locks. Copy their immutable
bindings under their own locks separately, then recheck session identity.

Existing Position callbacks receive outer begin, sampler before/after, outer
normal-completion and balanced finally. Default-NULL callbacks are inert. The
normal completion callback validates the retained generic outer-post capture;
finally restores before return to Action. Its separate receipt retains both
actual scoped-after and restored caller state. Finally performs conditional
cleanup on foreign SEH without suppressing/replacing the original exception.
Abnormal cleanup reads only resident scope storage and revalidated TLS storage;
it never dereferences an unwound native Value/frame/command/object.

Restoration requires the same thread/TLS provider/address, valid alignment and
writable mapping; contain write faults. STOP/phase/identity/nested/duplicate or
postcondition failure remains fatal even if the caller state is restored. A
changed TLS provider or failed store retains explicit restoration debt; do not
write to an alternate location or report completed cleanup. An unseeded refusal
never restores caller RNG. Unexpected nested execution invalidates the scope;
no claim that already executed native side effects can be rolled back.

Close new admission before restoring the existing Position hooks. Retain all
resident code/storage while calls can be in flight; record open/restore overlap
without waiting on engine threads. The existing patch ownership/protection/
flush failure accounting is unchanged. No new patch site or thunk is proposed.
