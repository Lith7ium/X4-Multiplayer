Proposed common contract

tools/dev/portable_rotation_reference.py is an offline original reference:

1. Parse at most256 ASCII characters of plain decimal, optional minus and dot,
   at least one digit. Convert the exact integer ratio to binary32 using nearest
   even. Missing or empty attributes mean+0; explicit negative zero is preserved.
   Reject whitespace, plus, exponent syntax, suffixes, locale-dependent spelling,
   nonfinite values and overflow. This is a deliberately strict common rule,
   not an emulation of either native permissive parser. All finite binary32
   values have an exact plain-decimal representation within this size bound.
2. Multiply once by the audited binary32 constant0x3c8efa35. The reference uses
   exact integer significands and explicitly rounds to binary32, including
   gradual underflow; it does not depend on FTZ/DAZ, host rounding mode or FMA.
3. Evaluate sin/cos for those exact radian bits. Generate pi/2 independently
   using Machin's identity and integer series at384 fractional bits. Reduce
   by the nearest multiple of pi/2, evaluate a bounded integer Taylor series on
   [-pi/4,pi/4], reconstruct the quadrant and round explicitly to binary32.
   No engine coefficient table, host libm or special +/-90 substitution is used.
4. Compose all nine coefficients with an explicit shared grouping and binary32
   rounding after every multiply/add. basis() records the audited mathematical
   pitch/yaw/roll convention as three stored basis vectors. It does not rename
   them world pose, alter position, or assume the native grouping is identical.
   This contract includes signed-zero results; no zero-bit cleanup is applied.

The actual mismatch inputs3fc90fdb/bfc90fdb produce exactly(+/-1,b33bbd2e).
The decimal midpoint above selects nearest-even3f63381a, then3c7dce65.
These are genuine common arithmetic decisions, not copied native transforms.

Remaining implementation and acceptance work

This Python oracle is not a production native evaluator, formal all-input
correct-rounding proof, throughput result, or Windows/Linux engine parity proof.
The sampled tests are not exhaustive over all finite binary32 angles. The basis
grouping is explicitly new common semantics, including possible signed-zero
differences from native paths. It needs review as a versioned arithmetic contract.

A practical native candidate can port the bounded integer algorithm into a
separate original C module using fixed-size unsigned limbs and explicit integer
rounding. Compare that module against this oracle under Windows and Linux
compilers, optimizations, rounding-mode/FTZ/FMA environments and real text
fixtures. Retain every output bit. Benchmark full import workload; do not assume
this Python reference's time or a12-ship fixture represents universe load cost.
Any cache must key exact inputs and retain exactly computed outputs.

The static-analysis lane owns XML lifetime/defaults/import-call ABI and ownership
review. Hooking one trig routine is insufficient because Windows has an inlined
Euler path and the native text parsers already differ. Before engine writes,
review a matched default-off integration that sees the same bounded raw angles,
preserves original call/return/lifetime behavior and changes only its owned
rotation output before publication. Unknown forms must refuse without native
fallback. Exact build/pins, snapshot/content and full unchanged portable hashes
remain required. A fresh reviewed two-native load must then demonstrate exact
frame0 equality and proceed through permits; this work has not done that.
