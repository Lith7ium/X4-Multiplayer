ORIGINAL CALL AND CLEANUP

Final eligibility and the one seed write are serialized against STOP. No lock
spans original. Every path invokes original once and preserves all four native
arguments and full RAX. A refused scope does not restore the caller RNG. A
completed seed store records ownership even if its readback fails; only that
ownership permits restoration of the verified TLS location.

Production __try/__finally clears this scope and restores the saved caller RNG
on normal return and native exception, if the current TLS pointer and writable
location remain valid. It performs no borrowed command/action/object reads on
abnormal return. A restoration fault is contained while the original exception
propagates. Lost TLS ownership refuses a stale write and remains a fatal receipt.
STOP overlap, duplicate use, nesting, missing assignment, changed candidates or
postcondition failure remain errors even when caller RNG restoration succeeds.

This scope removes one selected natural draw from the continuing caller stream.
Upstream draws, later position sampling and nonselected calls remain natural.
Existing enclosing Action/Values wrappers still lack full exception cleanup;
their open/failure evidence remains strict. This implementation only guarantees
its own tested scope cleanup, not engine exception recovery or a playable pass.
